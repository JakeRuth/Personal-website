# jakeruth.com

Personal website by Jake Ruth.

One InstallShield-style setup wizard at `/`, three experiences at `/xp/`, `/readme/`, `/saas/`, stitched by a Rubik's cube transition. Same Jake, three chromes.

Vanilla HTML/CSS/JS. No build step. Deployed to GitHub Pages from `master`.

> **Built with AI, reviewed by Jake.** Exact public framing wording TBD before re-push. See `CLAUDE.md`.

## Run locally

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000/`.
