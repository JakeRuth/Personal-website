Every Jake Ruth experience carries a small Setup badge in the corner. Click it and the installer comes back as a compact modal — same InstallShield chrome, same three flavors, no full page re-pick. Pick one and the next experience loads (through the transition-cube if you enable it).

This is a staging page. The content below is placeholder so the button has something to sit on top of. Scroll; the button stays put.

Why a persistent Setup button

The picker is the nav. Every other pattern we tried — topbar pills, a command palette, ambient cubes — added a second navigation metaphor on top of the wizard one. This pattern commits. You installed an experience; the installer lives in the tray; open it whenever you want to reinstall.

What this demo proves

One file, one mount call. Drop <link> and <script> tags into any experience, call WizardReopenNav.mount({ current: 'xp' }), and you're done. No build step, no framework, CDN-only. 

<link rel="stylesheet" href="../nav-wizard-reopen/styles.css" />
<script src="../nav-wizard-reopen/wizard-reopen-nav.js"></script>
<script>
  WizardReopenNav.mount({
    current: 'xp',                // which experience is loaded right now
    useTransitionCube: true,      // optional: solve-animation on confirm
  });
</script>
