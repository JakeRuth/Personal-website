# Concept 01 — SaaS Parody

A top-tier dark-mode SaaS marketing page (Linear / Vercel / Stripe energy) where the "product" being sold is Jake Ruth the engineer. Built with pure vanilla HTML / CSS / JS, no build step, no dependencies beyond Google Fonts over CDN. Open `index.html` directly via `file://` or serve the repo root with `python3 -m http.server`. All required sections are present: sticky nav, hero with gradient headline + pill badge + terminal mock, "Trusted by" logo row, 6-card features grid, 3-tier pricing, 3 testimonials, a changelog timeline, a CTA band, and a legalese-styled footer. Primary CTA emails `jake@stockunlock.com`; "View docs" links to `../../official_resume.pdf` so it resolves once the prototype is browsed from its own folder.

All logos in the "Trusted by" row are typographic stand-ins, not real marks. Testimonial quotes and names (Daniel Moretti, Priya Shah, Alex Kowalski) are fabricated as instructed. Pricing numbers are deliberately plausible-but-mocked ($250/hr etc.). Discoverable interactions: a cursor-following violet spotlight on desktop, magnetic-hover on every feature / pricing / testimonial card (mouse position drives a subtle translate + a radial glow via CSS custom props), a pulsing green status dot, a blinking terminal cursor, a sticky nav that gains a border + backdrop on scroll, smooth-scroll for in-page anchors, and a hidden easter egg: type "ship" anywhere on the page and the hero headline briefly blurs and lifts.

If I had more time I'd add scroll-triggered reveal animations on the features grid, an actual favicon / OG image, a tiny `/status` modal that fakes real uptime metrics, a dark-to-near-black hero gradient transition on scroll, and a better "logos" row that uses inline SVG stand-ins for each brand mark rather than unicode glyphs. I'd also wire the "Changelog" pill in the hero to an expanded modal of release notes written entirely in SaaS-patch-note voice.
