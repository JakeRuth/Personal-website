POST /api/hire

Initiates a hiring flow for the jake resource. Returns 201 Created on acceptance. Idempotent on email.

Body parameters

rolestringRequired. One of ic, tech-lead, founding, advisor.
stagestringRequired. Company stage. Best results at seed → Series B.
interestingbooleanRequired. Must be true.
emailstringYour email. Jake's will be returned in the response.
cURL Node Python 
# Contact Jake directly
curl mailto:jake@stockunlock.com \
  -H "Content-Type: application/json" \
  -d '{
    "role": "founding",
    "stage": "seed",
    "interesting": true,
    "email": "you@yourstartup.com"
  }'
Response201 Created
{
  "jake": "jake@stockunlock.com",
  "response_time": "~24h",
  "status": "interested",
  "availability": "taking calls"
}
GET /api/status

Returns the current availability and on-call status of the jake resource.

Response fields

availablebooleanWhether Jake is taking new engagements.
latency_msintegerMean Slack response latency, trailing 7 days.
current_focusstringWhat Jake is currently heads-down on.
cURL 
curl https://ruth.systems/api/status
Response200 OK
{
  "available": true,
  "latency_ms": 18,
  "current_focus": "next chapter",
  "on_call": "weekdays ET",
  "cube_pb": "13.95s avg"
}
PATCH /api/role

Updates the role descriptor on the jake resource. Returns the new role in the response. Side effect: a calendar invite.

Body parameters

titlestringProposed title.
scopestringIC / lead / founding / advisor.
compensationobjectCash + equity. Market or better.
cURL 
curl -X PATCH mailto:jake@stockunlock.com \
  -d '{ "scope": "founding" }'
