POST /api/hire

Initiates a hiring flow for the jake resource. Returns 201 Created on acceptance. Idempotent on email. Prices are not part of this payload — that conversation happens over email.

Body parameters

rolestringRequired. One of ic, founding, advisor.
stagestringRequired. Company stage. Best fit: seed → Series B.
interestingbooleanRequired. Must be true.
emailstringYour email. Jake's will be returned.
cURL Node Python 
# Contact Jake directly
curl mailto:jake@stockunlock.com \
  -H "Content-Type: application/json" \
  -d '{
    "role": "founding",
    "stage": "seed",
    "interesting": true,
    "email": "you@yourstartup.com"
  }'
Response201 Created

GET /api/status

Returns the current availability of the jake resource. Always fresh, never cached longer than a cube solve.

Response fields

availablebooleanWhether Jake is taking new engagements.
latency_msintegerMean response latency on email, trailing 7 days.
current_focusstringWhat I'm heads-down on today.

GET /api/cube/solve

Returns a valid move sequence that solves the provided cube state. Strategy: beginner layer-by-layer. Implementation: BFS per stage against a 54-facelet model. See the cube panel above to run it.

PATCH /api/role

Updates the role descriptor on the jake resource. Side effect: a calendar invite.
